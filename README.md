# Arc Points Leaderboard

An onchain points leaderboard built on Arc Testnet using Arc Studio.

Users can connect their wallet, register a username, earn test points, and view the leaderboard through an onchain application.

## Live Demo

https://lucky-malabi-dec61e.netlify.app/

## Smart Contract

## Features

- Wallet connection
- Onchain username registration
- Test points system
- Points leaderboard
- Smart contract interaction
- Built on Arc Testnet
- Owner-controlled point awards
- Built and tested with Arc Studio
